Здорово, солнышки! 👋

Помните, недавно я рассказывал про Open Claude как про альтернативу Claude Code? Так вот, кажется, появился уже «убийца убийцы»🔫

На сцену выходит Mino Code от Xiaomi #AI

Мало нам было DeepSeek, который обещал потеснить ChatGPT (кстати, кто-нибудь вообще ещё активно пользуется DeepSeek?), так теперь китайцы решили зайти и на территорию AI-инструментов для разработки.

И, знаете... на первый взгляд получилось довольно интересно.

Что имеем:
🟠 интерфейс и взаимодействие очень напоминают Open Claude — по сути, он и лежит в основе проекта;
🟠 модель с практически неограниченным контекстом;
🟠 бесплатная версия, которая по ряду бенчмарков обходит многих конкурентов.

При этом инструмент вообще не пытается быть универсальным.

Никаких презентаций, картинок, таблиц или написания статей. Только код. Только приложения. Только сайты.
Отдельно понравилось, что не нужно разбираться с десятком моделей и API. Ставите через Git, выбираете бесплатную модель — и можно сразу работать.

Я пару вечеров поковырялся с ним на виртуалке😎

Как бесплатная альтернатива Claude Code — очень достойно. Да и Open Claude он тоже вполне способен заменить. Правда, за бесплатность придётся платить временем: на некоторые задачи Mino Code думает и приходит к решению заметно дольше, чем Claude😒

Но если бюджет ограничен, а хороший AI-помощник для разработки нужен уже сейчас — вариант определённо стоит попробовать.
Короче, сладкая халява для разработчиков. Разбирайте🤗
