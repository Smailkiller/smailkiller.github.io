# Трактирная книга

Сайт-архив Telegram-канала в стиле «страдающего средневековья». Живёт по адресу
`https://smailkiller.github.io/tavern/`. Портфолио в корне репозитория не трогается.

Страницы статичные: каждый пост канала превращается в отдельный «свиток» (`scroll/<номер>.html`),
поэтому поисковики его видят. Фильтры, поиск и прочая магия работают в браузере без сервера.

## Как залить свой канал

1. Telegram Desktop → канал → ⋮ → **Экспорт истории чата**. Отметьте «Фотографии», формат
   **«Машиночитаемый JSON»** (HTML тоже подойдёт).
2. Из корня репозитория:

   ```
   pip install pillow          # необязательно: сжимает картинки до 1200px
   python tavern/_src/build.py --export "E:\_ИИ агенты\клод\таверна\ChatExport_2026-09-26"
   ```

   Сборщик разложит посты по комнатам по хэштегам, скопирует картинки в `tavern/media/tg/`
   и напишет, какие хэштеги ни к одной комнате не привязаны.
3. Закоммитьте и запушьте. Через минуту GitHub Pages обновит сайт.

Посты, импортированные в первый раз, сохраняются в `_src/posts.json`. Если поправили только каталоги
или конфиг, достаточно запустить `python tavern/_src/build.py` без `--export`.

## Что где править

| Файл | Что внутри |
|---|---|
| `_src/config.json` | название, **ссылка на канал и его латинский username** (для кнопок «Обсудить в канале»), комнаты: `id`, `name`, `day`, `hashtags`, `kind` (`ai`, `hookah`, `garden`, `minis`, `shelf`, `feed`), для `shelf` — `types` |
| `_src/catalog/hookah.json` | забивки и миксы: вкусы, особые метки («не приторно», «лимитка»), вердикт |
| `_src/catalog/garden.json` | растения и дневник роста |
| `_src/catalog/minis.json` | фракции и миниатюры |
| `_src/catalog/shelf.json` | книги, манга, манхва, аниме, мультфильмы (комнаты «Листаем» и «Лис в экране» берут свои типы) |
| `_src/catalog/ai.json` | закреплённые гайды в келье ИИ |
| `_src/pixel_scene.py` | рисует пиксельный зал: `python tavern/_src/pixel_scene.py` (нужны pillow и numpy), результат в `assets/scene/` |
| `assets/tavern.css`, `assets/tavern.js` | стили и скрипты |

Каталоги собраны из постов канала. Вердикты: `любимое`, `советую`, `приятно`, `спорно`, `мимо`,
`без вердикта`. Поле `post` — номер поста в канале: карточка сошлётся на его свиток. Если поставить
записи `"example": true`, на ней появится печать «ОБРАЗЕЦ». Фото кладите в `tavern/media/…` и указывайте путь от папки `tavern/`.

Страницы `*.html`, `scroll/`, `sitemap.xml` и `assets/search-index.js` генерируются, руками их не правьте.

## Новая комната

Добавьте её в `config.json` с `"kind": "feed"` — получится лента свитков с поиском и метками.
Чтобы у комнаты появился предмет в зале, добавьте его в `HOT` в `pixel_scene.py` и перерисуйте зал.

## Картинки к постам

Сейчас в архиве только текст: в `result.json` фото не входят. Чтобы появились картинки, запустите
сборщик на полной папке экспорта (с подпапкой `photos`) — он сам сожмёт и разложит их по свиткам.
